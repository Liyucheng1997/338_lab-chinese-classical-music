# 丝竹三韵 · 古筝 二胡 唢呐 琵琶 三维物理建模演奏

用 Three.js 在殿堂场景中建模古筝、二胡、唢呐、琵琶，由四位程序化建模的乐师实时演奏。声音全部由 JavaScript 物理模型合成（无采样音源）；三维动画直接读取合成时产生的演奏数据——哪根弦、哪一品、哪个手指、推弓还是拉弓、按音、揉弦、摇指、轮指、扫弦、花舌——并与音频时钟同步。场景的布光、殿堂、后期与程序化纹理参照 `336_中国古代编钟` 项目。

**在线体验：** https://liyucheng1997.github.io/338_lab-chinese-classical-music/ （建议电脑端 Chrome / Edge，佩戴耳机）

版本 1.2（新增琵琶与琵琶女、依据演奏录像扒谱的《十面埋伏》，并按录像重制《百鸟朝凤》）。推送到 `main` 后由 GitHub Actions 运行 `npm run build`（`tools/build-pages.js` 生成 `dist/`）并发布到 GitHub Pages。

## 启动

安装 Node.js 20 或更高版本，在项目目录运行：

```powershell
npm install    # 仅安装 three.js
npm start
```

浏览器打开 <http://localhost:8080>，点击「入席聆听」。保持终端运行，按 Ctrl+C 停止服务；端口被占用时运行 `npm start -- 8081`。

请通过本地服务器打开，不要直接双击 HTML：ES 模块、Worker 与 AudioWorklet 需要 HTTP 环境。建议电脑端 Chrome / Edge 并佩戴耳机。进入后四首曲子会在后台依次合成（每首约十几到三十几秒，视设备而定），曲目卡片上显示进度；点选的曲目优先合成。

## 三维模型

| 乐器 | 建模 | 演奏动画 |
| --- | --- | --- |
| 古筝 | 163 cm 拱形桐木面板（水墨梅枝与题字）、红木侧板回纹、前后岳山、21 个人字雁柱斜列、21 弦（每组“5”音为绿弦）、琴尾弦钉盒、交叉筝架 | 右手戴玳瑁义甲，按音符选指：托（拇指外拨）、抹（食指内勾）、勾（中指），和弦分指同拨，摇指为拇指高速往复，花指/刮奏连续扫弦；左手在雁柱左侧按弦（按音时弦被压下），长音揉弦。被拨的弦按衰减包络振动发光 |
| 二胡 | 六角琴筒（前口蟒皮、后口镂空音窗）、乌木琴杆与卷首、双轴、千斤、琴码、内外弦、红穗；竹弓马尾穿在两弦之间 | 右手持弓：非连音即换弓，推 / 拉交替，弓速随力度与时值；弓毛靠内弦或外弦。左手指位由音高算出（距千斤的弦长比例 = 1 − f₀/f），按把位选食、中、无名、小指，滑音平移、揉弦上下颤动；发声段从指位振动到琴码 |
| 唢呐 | 双簧哨子、气牌、铜芯子、八孔木杆（前七后一，铜箍）、指数喇叭铜碗、红绸 | 指法按“筒音作 5”：全按为 E4，自下而上逐孔开放，变化音半孔，高八度开背孔；换音提前 30 ms 抬指。铜碗随音量发光，碗口发出声波环，花舌时哨子颤动 |
| 琵琶 | 梨形桐木面板（微拱、黑线镶边）、红木鼓背、琴颈上六个骨质“相”、面板上二十四根竹“品”（按十二平均律半音间距排列）、向后弯的弦槽与四个轸子、如意琴头、雕花覆手、四弦（子弦在演奏者右手一侧） | 左手按品：由音高与弦算出品位，食、中、无名、小指各管一品，超出范围即换把；推拉时手指横推、长音吟揉。右手在覆手与最低一品之间：单音弹（食指外弹）、挑（拇指内挑）交替，轮指时小、无名、中、食指依次弹出再由拇指挑回，扫拂时手划过四弦。发声的弦从按弦点振动到覆手 |

## 乐师

四位乐师全部用代码建模（`web/scene/figure/`），载入时生成：

| 乐师 | 造型 | 动作 |
| --- | --- | --- |
| 古筝少女 | 鹅蛋脸、丹凤眼、樱唇与眉心花钿；中分后髻、双垂鬟扎红绳、垂发，金步摇与珍珠耳坠；月白大袖上襦、绛红卷草纹交领缘、石榴红齐胸襦裙（束胸带、飘带），坐绣墩，绣鞋 | 眼随拨弦的手移动、眨眼；上身向两手中点微倾，左手远按时侧身；随音头轻点头，步摇垂珠与耳坠随头部摆动 |
| 盲眼老琴师 | 颧骨突出、两颊凹陷、双目闭合，灰白胡茬、山羊须与八字须，额纹鱼尾纹；毡帽、圆墨镜；洗旧的灰蓝长衫（大襟盘扣、立领、挽白袖），黑裤布鞋，坐方凳，二胡立在左腿上 | 上身随弓的推拉转动、侧倾；盲人侧耳的姿态，头微仰、随乐缓摇 |
| 陕北唢呐匠 | 方脸浓眉、络腮胡茬与髭须；羊肚手巾在额前打结；黑对襟袄与白一字扣、红腰带、绑腿与黑布鞋，站立吹奏 | 吹奏时两腮鼓起，随音量后仰、随音头前点；唢呐与上身同在一个摆动架上，始终衔在口中 |
| 琵琶女 | 侧分低髻、碧玉簪与白玉兰、珍珠耳坠；孔雀蓝真丝旗袍（白梅与暗金缠枝、大襟象牙白滚边、盘扣、立领），坐绣墩，琵琶竖抱于左腿 | 目光多在左手按品处；上身随力度微微前倾，强音时轻点头 |

头部用有向距离场（SDF）平滑组合颅骨、面部轮廓、颧、颊、鼻、唇、眼睑与耳，沿径向投影成网格；眨眼与鼓腮是变形目标，肤色、唇、眉、皱纹、胡茬按三维位置逐像素绘制。头发为贴合头皮的发壳（逐像素发际线透明）加管状发束与发片。裙与长衫下摆在载入时用位置动力学解算，搭在大腿与膝头、垂落到地面。手臂以两段 IK 从肩接到乐器上的手，袖子（含宽袖下垂）每帧重建。

## 使用

- **听曲**：点击右侧曲目卡片播放，镜头移到对应乐器；再次点击或按空格暂停。段落名称以字幕显示，底部卷帘显示音符与当前技法（托、抹、按音、摇指、分弓、揉弦、花舌、弹挑、轮指、扫弦、绞弦……）。
- **定位**：点击进度条；进度条获得焦点后左右键跳转 5 秒，Home/End 到开头/末尾。
- **视角**：拖动旋转、滚轮缩放、右键平移；「运镜」开启时演奏中缓慢环绕，操作后暂停 5 秒。「全景」按钮回到总览。
- **律制**：十二平均律、五度相生律、纯律，切换后重新合成当前曲目（亲手演奏使用十二平均律）。
- **导出**：合成完成后点击「下载 WAV」，得到 44.1 kHz、16 位立体声。
- **亲手演奏**（用鼠标直接点场景中的乐器）：
  - 古筝：点击雁柱与琴头之间的弦拨奏，按住划过多根弦即刮奏；按住雁柱与琴尾之间的弦为按音（升全音）。
  - 二胡：在千斤与琴码之间按住琴弦发声，上下拖动滑音（越往下越高，低于 A4 自动换内弦），弓自动推拉换弓；可选吸附五声音阶。
  - 唢呐：按住木杆上的音孔处吹奏，沿管身拖动换音。
  - 琵琶：点击琴弦弹奏，点在哪一品之上左手就按在那一品（最低一品以下为空弦）；按住横向划过四弦即扫弦。
  - 键盘 `A S D F G H J K L ;`：演奏当前选中的乐器（古筝中音区 / 二胡 D 调五声 / 唢呐 A 调五声 / 琵琶 D 调五声），松开停止。Esc 停止全部发声。
- **画质**：「流畅」关闭镜面地面与阴影，适合性能较弱的设备。

## 从演奏录像扒谱

`tools/transcribe/` 是一条可重跑的扒谱流水线（Python）：

| 步骤 | 琵琶《十面埋伏》 | 唢呐《百鸟朝凤》 |
| --- | --- | --- |
| 1 提取音频 | ffmpeg 转单声道 44.1 kHz | 同左 |
| 2 转写 | basic-pitch（ONNX）得到音符、起音、音高轮廓后验图 | 同左 |
| 3 音高 | 四根空弦实测为 B♭ E♭ F B♭（比标准定弦高约 1.24 个半音，胶片转速或当年定弦），整体移到 A d e a | 录音比 A4 = 440 Hz 高约 38 音分；再按 20 秒窗口估计局部音准，吸附到 A 大调音阶 |
| 4 成音 | 起音后验的峰 → 拨弦事件（去泛音）；同音高每秒 9 下以上的重复 → 轮指 `~`；同时起音 → 和音 / 扫弦；“九里山大战”之后频谱平坦的噪声段 → 绞弦 `x` | “天际线”主旋律：唢呐几乎总在乐队之上，取唢呐音域内最高的可信音高（Viterbi 平滑）→ 切分音符，识别滑音 `/ \`、倚音 `{ }`、两音快速交替 `< >`，删去唢呐停顿时追踪到的乐队声部与八度错误 |
| 5 节拍 | 音频起音强度 + 音头脉冲，逐帧速度（♩ 55–160）Viterbi 平滑后做动态规划拍点跟踪 | 同左 |
| 6 写谱 | 2/4 拍，十六分音符网格（同一拍挤两个音时改用三十二分），每小节写实测速度，力度按小节响度分五档 | 同左，休止按实际收音时刻写出 |

basic-pitch 的后验图帧率并不均匀：它按 2 秒窗口推理，每窗只保留 142 帧、窗口步进 36164 个采样，整体约 86.58 帧/秒而不是 86.13；`tools/transcribe/common.py` 按真实窗口结构换算，否则五分钟后会差出 0.6 秒以上。

```powershell
pip install librosa basic-pitch onnxruntime   # 另需 ffmpeg（或 imageio-ffmpeg）
python tools/transcribe/run.py shimian        # 写出 src/score/shimian.js
python tools/transcribe/run.py bainiao        # 写出 src/score/bainiao.js
python tools/transcribe/evaluate.py shimian   # 与原录音比较
```

客观比较（`evaluate.py`，合成音频由网页同一套物理建模渲染）：

- 《十面埋伏》：用同一个 basic-pitch 分别“听”原录音与合成，音符后验图逐帧比较（±2 帧）召回率 0.88、精确率 0.43、F 值 0.57。精确率偏低主要因为合成的琴弦余音比老影片录音长，以及绞弦段的噪声被听成音高。
- 《百鸟朝凤》：原录音唢呐主旋律的有声帧中 72% 在合成里也有音；两者都发声的帧中 72% 音高相差不到半音、82% 不到一个半音（其余多在滑音、颤音与鸟鸣段）。

## 验证与离线导出

```powershell
npm test                         # 7 项运行时回归 + 33 项 DSP/乐谱/整曲音频检查
npm run test:runtime              # 实时止音、换弦、力度、WAV 和静态服务回归
npm run render                   # 四首完整 WAV + output/report.json
npm run tune                     # 四首曲目音准报告
npm run tune -- --tuning=just     # 纯律音准报告
npm run render -- --tuning=pythagorean
```

导出位于 `output/`：`yuzhou.wav`、`erquan.wav`、`bainiao.wav`、`shimian.wav`，其他律制文件带有对应后缀。`report.json` 记录时长、采样率、峰值、RMS 和音准摘要。

默认十二平均律在本次验证中的结果：古筝 21 根空弦最大偏差 0.42 音分；琵琶四弦在 0–19 品的最大偏差 1.38 音分；二胡实测 523 个稳定音，平均绝对偏差 1.07、最大 4.46 音分；唢呐（新谱）实测 464 个稳定音，平均绝对偏差 1.00、最大 4.32 音分。滑音、花舌和极短音会跳过。古筝复调通过独立弦/按音组合测量，不将混响中的复调音准当作单音统计。

音准与有限值、响度、削波检查可自动复现；音色喜好仍需实际试听。合成器是乐器声学行为的近似模型。

动画是“无状态”的：每一帧只根据当前时间在音符表里查找前后音符来计算手、弓、指孔的姿态，因此拖动进度条、暂停、变更律制后都能立即对齐。修改曲谱时编辑 `src/score/*.js`，新增曲目在 `src/pieces.js` 注册。文字简谱的语法位于 `src/score/jianpu.js` 文件顶部，例如 `1` 为主音、`1'` 为高八度、`1_` 为八分音符、`[1 3 5]` 为和弦；琵琶另有 `x`（绞弦）、`o`（泛音），`-_` / `-__` 把前一音延长半拍 / 四分之一拍。修改后运行 `npm test` 检查小节拍数和音频健康度。

乐器与手的造型是依据常见形制的程序化近似，指法与运弓规则是简化的演奏法模型，并非对某位演奏家的动作捕捉。
