# 丝竹三韵 · 古筝 二胡 唢呐 三维物理建模演奏

用 Three.js 在殿堂场景中建模古筝、二胡、唢呐，由“隐形乐师”的双手实时演奏。声音全部由 JavaScript 物理模型合成（无采样音源）；三维动画直接读取合成时产生的演奏数据——哪根弦、哪个手指、推弓还是拉弓、按音、揉弦、摇指、花舌——并与音频时钟同步。场景的布光、殿堂、后期与程序化纹理参照 `336_中国古代编钟` 项目。

**在线体验：** https://liyucheng1997.github.io/338_lab-chinese-classical-music/ （建议电脑端 Chrome / Edge，佩戴耳机）

版本 1.0。推送到 `main` 后由 GitHub Actions 运行 `npm run build`（`tools/build-pages.js` 生成 `dist/`）并发布到 GitHub Pages。

## 启动

安装 Node.js 20 或更高版本，在项目目录运行：

```powershell
npm install    # 仅安装 three.js
npm start
```

浏览器打开 <http://localhost:8080>，点击「入席聆听」。保持终端运行，按 Ctrl+C 停止服务；端口被占用时运行 `npm start -- 8081`。

请通过本地服务器打开，不要直接双击 HTML：ES 模块、Worker 与 AudioWorklet 需要 HTTP 环境。建议电脑端 Chrome / Edge 并佩戴耳机。进入后三首曲子会在后台依次合成（每首约十几到三十几秒，视设备而定），曲目卡片上显示进度；点选的曲目优先合成。

## 三维模型

| 乐器 | 建模 | 演奏动画 |
| --- | --- | --- |
| 古筝 | 163 cm 拱形桐木面板（水墨梅枝与题字）、红木侧板回纹、前后岳山、21 个人字雁柱斜列、21 弦（每组“5”音为绿弦）、琴尾弦钉盒、交叉筝架 | 右手戴玳瑁义甲，按音符选指：托（拇指外拨）、抹（食指内勾）、勾（中指），和弦分指同拨，摇指为拇指高速往复，花指/刮奏连续扫弦；左手在雁柱左侧按弦（按音时弦被压下），长音揉弦。被拨的弦按衰减包络振动发光 |
| 二胡 | 六角琴筒（前口蟒皮、后口镂空音窗）、乌木琴杆与卷首、双轴、千斤、琴码、内外弦、红穗；竹弓马尾穿在两弦之间 | 右手持弓：非连音即换弓，推 / 拉交替，弓速随力度与时值；弓毛靠内弦或外弦。左手指位由音高算出（距千斤的弦长比例 = 1 − f₀/f），按把位选食、中、无名、小指，滑音平移、揉弦上下颤动；发声段从指位振动到琴码 |
| 唢呐 | 双簧哨子、气牌、铜芯子、八孔木杆（前七后一，铜箍）、指数喇叭铜碗、红绸 | 指法按“筒音作 5”：全按为 E4，自下而上逐孔开放，变化音半孔，高八度开背孔；换音提前 30 ms 抬指。铜碗随音量发光，碗口发出声波环，花舌时哨子颤动 |

## 使用

- **听曲**：点击右侧曲目卡片播放，镜头移到对应乐器；再次点击或按空格暂停。段落名称以字幕显示，底部卷帘显示音符与当前技法（托、抹、按音、摇指、分弓、揉弦、花舌……）。
- **定位**：点击进度条；进度条获得焦点后左右键跳转 5 秒，Home/End 到开头/末尾。
- **视角**：拖动旋转、滚轮缩放、右键平移；「运镜」开启时演奏中缓慢环绕，操作后暂停 5 秒。「全景」按钮回到总览。
- **律制**：十二平均律、五度相生律、纯律，切换后重新合成当前曲目（亲手演奏使用十二平均律）。
- **导出**：合成完成后点击「下载 WAV」，得到 44.1 kHz、16 位立体声。
- **亲手演奏**（用鼠标直接点场景中的乐器）：
  - 古筝：点击雁柱右侧的弦拨奏，按住划过多根弦即刮奏；按住雁柱左侧的弦为按音（升全音）。
  - 二胡：在千斤与琴码之间按住琴弦发声，上下拖动滑音（越往下越高，低于 A4 自动换内弦），弓自动推拉换弓；可选吸附五声音阶。
  - 唢呐：按住木杆上的音孔处吹奏，沿管身拖动换音。
  - 键盘 `A S D F G H J K L ;`：演奏当前选中的乐器（古筝中音区 / 二胡 D 调五声 / 唢呐 A 调五声），松开停止。Esc 停止全部发声。
- **画质**：「流畅」关闭镜面地面与阴影，适合性能较弱的设备。

## 验证与离线导出

```powershell
npm test                         # 7 项运行时回归 + 26 项 DSP/乐谱/整曲音频检查
npm run test:runtime              # 实时止音、换弦、力度、WAV 和静态服务回归
npm run render                   # 三首完整 WAV + output/report.json
npm run tune                     # 三首曲目音准报告
npm run tune -- --tuning=just     # 纯律音准报告
npm run render -- --tuning=pythagorean
```

导出位于 `output/`：`yuzhou.wav`、`erquan.wav`、`bainiao.wav`，其他律制文件带有对应后缀。`report.json` 记录时长、采样率、峰值、RMS 和音准摘要。

默认十二平均律在本次验证中的结果：古筝 21 根空弦最大偏差 0.42 音分；二胡实测 523 个稳定音，平均绝对偏差 1.07、最大 4.46 音分；唢呐实测 301 个稳定音，平均绝对偏差 0.99、最大 3.65 音分。滑音、花舌和极短音会跳过。古筝复调通过独立弦/按音组合测量，不将混响中的复调音准当作单音统计。

音准与有限值、响度、削波检查可自动复现；音色喜好仍需实际试听。合成器是乐器声学行为的近似模型。

## 代码位置

```text
web/index.html      页面（three.js 通过 import map 从 node_modules 加载）
web/app.js          载入、合成队列、播放、音频时钟驱动动画、拾取与键盘演奏、运镜、卷帘
web/scene/          三维场景
  Stage.js          渲染器、相机、布光、Bloom / 暗角后期（沿用编钟项目）
  Hall.js           殿堂、镜面地面、窗光、演奏台、山水屏风、灯台、浮尘
  Guzheng.js        古筝模型与左右手演奏逻辑
  Erhu.js           二胡模型、运弓分段与左手指位
  Suona.js          唢呐模型与指法表
  Hand.js           程序化手（掌、五指三关节、义甲、前臂淡出）与指尖定位
  VibString.js      可振动 / 可按压的弦与振动残影
  Effects.js        声波环、光尘
  textures.js       程序化纹理（木纹、古筝面板、蟒皮、黄铜、漆器、山水、地毯……）
web/worker.js       后台整曲合成
web/worklet.js      实时演奏引擎（AudioWorklet）
src/dsp/            三种乐器、延迟线、滤波器、调律、混响和限幅
src/score/          文字简谱解析器及三首曲谱
src/perform/        简谱事件到滑音、揉弦、摇指、花舌等演奏参数（同时输出供动画使用的演奏数据）
src/render.js       浏览器 / Node 共用的整曲渲染管线
src/analysis/       基频检测与逐音验证
tools/              本地服务、测试、批量导出、音准 / 频谱分析
output/             导出的音频与报告
```

动画是“无状态”的：每一帧只根据当前时间在音符表里查找前后音符来计算手、弓、指孔的姿态，因此拖动进度条、暂停、变更律制后都能立即对齐。修改曲谱时编辑 `src/score/*.js`，新增曲目在 `src/pieces.js` 注册。文字简谱的语法位于 `src/score/jianpu.js` 文件顶部，例如 `1` 为主音、`1'` 为高八度、`1_` 为八分音符、`[1 3 5]` 为和弦。修改后运行 `npm test` 检查小节拍数和音频健康度。

乐器与手的造型是依据常见形制的程序化近似，指法与运弓规则是简化的演奏法模型，并非对某位演奏家的动作捕捉。
